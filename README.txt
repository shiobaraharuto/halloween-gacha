ハロウィン彼氏ガチャ（無料・5種類）

1. index.html をブラウザで開くとガチャを試せます。
2. ボイスを再生するには audio フォルダに以下の MP3 を置いてください。
   01-vampire.mp3（吸血鬼）
   02-demon.mp3（悪魔）
   03-wolf.mp3（狼男）
   04-ghost.mp3（おばけ）
   05-cat.mp3（黒猫）
3. GitHub Pages で無料公開する場合は、公開リポジトリに index.html と audio フォルダをアップロードし、Settings > Pages > Deploy from a branch > main / (root) を選択します。公開URLは通常 https://ユーザー名.github.io/リポジトリ名/ です。
4. 図鑑と回数は同じブラウザの localStorage に保存されます。別端末には同期しません。プライベートブラウズやデータ消去でリセットされます。
5. 5種類はすべて20%の抽選確率です。レアリティと課金はありません。
